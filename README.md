# BlackNote 📓

BlackNote is a premium local-first web clipping and note-taking browser extension designed with speed, security, and aesthetics in mind. It allows users to capture web clippings, write notes, and sync them seamlessly to the cloud (AWS S3 & DynamoDB).

## Features
- **Offline-First**: Access and edit your notes and clippings without an internet connection.
- **Vibrant & Clean UI**: Built with a sleek dark mode and modern design aesthetics.
- **Web Clipping**: Save high-fidelity snapshots of web pages using state-of-the-art HTML capture.
- **Cloud Sync**: Securely sync your data with AWS (S3 & DynamoDB) across multiple devices.
